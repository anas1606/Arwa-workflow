# Arwa Workflow

Factory production UI (frontend-first). Backend, DB, and mobile shell come later.

## Structure

```text
Arwa-Workflow/
├── apps/
│   ├── web/       # React + Vite UI (active)
│   ├── api/       # Backend later (NestJS + PostgreSQL)
│   └── mobile/    # Capacitor shell later
└── packages/
    └── shared/    # Shared types later
```

## Run UI

```bash
npm install
npm run dev
```

Open http://localhost:5173
